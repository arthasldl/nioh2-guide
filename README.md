# 仁王2 攻略帐 | Nioh 2 Complete Guide

一个专注于《仁王2》(Nioh 2) 的游戏攻略查询网站，采用纯前端单文件架构，界面美观、检索便捷。

## 功能特性

- 🏠 **首页** — Hero 主视觉、攻略分类导航、精选攻略推荐、游戏介绍
- 📚 **攻略中心** — 分类筛选、攻略卡片浏览、全文搜索
- 📖 **攻略详情** — 文章阅读、侧边目录导航、相关攻略推荐
- ⚔️ **武器图鉴** — 11 种武器分类展示，含上手难度评估
- 👹 **BOSS 图鉴** — BOSS 卡片展示，含类型标签与弱点属性
- 🛡️ **配装推荐** — 配装方案卡片，含输出/生存/难度评级
- 🔍 **全站搜索** — 实时搜索攻略标题与内容
- 📱 **响应式设计** — 适配桌面端、平板与移动端
- 🌙 **暗黑主题** — 契合仁王2 暗黑战国风格的视觉设计

## 技术栈

- 纯 HTML5 + CSS3 + 原生 JavaScript（无框架、无构建工具）
- Hash 路由实现多页面切换
- Google Fonts (Noto Serif SC / Noto Sans SC)
- 单文件自包含，可直接部署到任意静态托管平台

## 项目结构

```
nioh2-guide/
├── index.html      # 网站主文件（包含全部 CSS/JS）
├── README.md       # 项目说明
└── assets/         # 本地素材备份（不被网站引用）
    ├── drop-table.jpg

```

## 本地运行

直接用浏览器打开 `index.html` 即可，无需任何服务器或依赖安装。

```bash
# 方式一：直接双击打开
# 方式二：使用本地服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 部署

### GitHub Pages

1. 将本项目推送到 GitHub 仓库
2. 进入仓库 Settings → Pages
3. Source 选择 `main` 分支，根目录 `/`
4. 保存后即可通过 `https://<用户名>.github.io/<仓库名>/` 访问

### 其他静态托管

可直接部署到 Vercel、Netlify、Cloudflare Pages 等平台，无需构建配置。
